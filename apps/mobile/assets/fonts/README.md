# Mobile fonts

Drop these `.ttf` files in this folder to ship Geist on the mobile build:

- `Geist-Regular.ttf`
- `Geist-Medium.ttf`
- `Geist-SemiBold.ttf`
- `GeistMono-Regular.ttf`
- `GeistMono-Medium.ttf`

Source: <https://github.com/vercel/geist-font>. License: SIL OFL.

The app falls back to the platform sans-serif if any font is missing — the
visual rhythm degrades but everything still renders.
